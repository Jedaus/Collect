## 관계 그래프 분석 API 최종 요구사항 및 UX 영향 분석

CEO님의 지시에 따라 관계 그래프 분석 API에 포함되어야 할 핵심 기능(F1~F5 심리 점수 및 관계 연결성)에 대한 최종 요구사항을 정리하고, 이것이 사용자 경험(UX)에 미치는 영향을 분석하여 개발 우선순위를 제시합니다.

### 1. 핵심 기능 요구사항 정의

관계 그래프 분석 API(`GET /api/v1/relationships/{relationship_id}/graph`)는 단순한 연결 정보 제공을 넘어, 관계의 **감정적 맥락**과 **잠재적 가치**를 정량화하여 사용자에게 제공해야 합니다.

#### 1.1. 관계 심리 점수 (F1~F5) 요구사항
이 점수는 관계의 질적 깊이를 측정하며, 데이터 모델링의 핵심이 됩니다.

| 지표 | 정의 (심리학적 맥락) | 데이터 모델링 요구사항 | API 반영 방식 |
| :--- | :--- | :--- | :--- |
| **F1 (신뢰/Trust)** | 관계의 안정성과 상호 믿음의 정도 | 1~5점 척도 (1: 불신, 5: 절대적 신뢰) | 관계 그래프의 노드(Node) 가중치로 반영 |
| **F2 (친밀도/Intimacy)** | 관계의 감정적 공유 및 깊이의 정도 | 1~5점 척도 (1: 얕음, 5: 깊은 유대감) | 관계 간의 연결 강도(Edge Weight) 산출에 사용 |
| **F3 (공유 활성화/Sharing)** | 관계 내에서 정보나 경험을 공유하는 빈도 및 의지 | 0~100% 또는 1~5점 척도 | 관계 그래프 내의 상호작용 흐름(Flow) 지표로 반영 |
| **F4 (상호 지원/Support)** | 어려움에 처했을 때 서로를 지지하는 정도 | 1~5점 척도 (1: 지지 없음, 5: 적극적 지원) | 관계 그래프의 연결 밀도(Density) 및 균형 지표로 반영 |
| **F5 (유대감/Bond)** | 관계의 지속성과 감정적 결속의 깊이 | 1~5점 척도 (1: 약함, 5: 강한 유대) | 관계 그래프의 중심성(Centrality) 지표 가중치로 반영 |

**최종 요구사항:** 모든 F1~F5 점수는 단순한 수치가 아닌, **관계 그래프의 노드 및 엣지(연결)의 가중치**로 변환되어야 합니다.

#### 1.2. 관계 연결성 요구사항
단순 연결을 넘어, 관계의 역동성과 흐름을 분석하는 지표를 포함해야 합니다.

*   **연결 밀도 (Density):** 특정 관계 내에서 발생하는 상호작용의 빈도와 깊이를 측정하여, 관계의 '밀도'를 수치화합니다.
*   **감정 흐름 점수 (Emotional Flow Score):** F1~F5 점수들의 시간적 흐름(Timeline)을 분석하여, 관계가 긍정적/부정적 방향으로 어떻게 발전해왔는지(추억 아카이빙의 흐름)를 시각화합니다.
*   **관계 중심성 (Centrality):** 해당 관계가 사용자의 전체 관계 네트워크 내에서 얼마나 중요한 위치(핵심 축)를 차지하는지를 측정합니다.

### 2. 사용자 경험(UX) 영향 분석

이러한 정량적 데이터는 사용자가 '금전' 중심의 모금 플랫폼에서 **'관계 중심의 경험 아카이빙 플랫폼'**으로 전환하는 데 결정적인 역할을 합니다.

| 데이터 유형 | UX 변화 | 사용자 경험의 핵심 가치 |
| :--- | :--- | :--- |
| **F1~F5 심리 점수** | 관계의 '질'을 수치화하여 객관적으로 인지. | **관계의 깊이 인지:** 사용자는 단순히 '누구와 모였는가'가 아니라 '얼마나 깊게 연결되어 있는가'를 이해하게 됨. |
| **연결 밀도/흐름 점수** | 관계의 역동성과 과거의 추억 흐름을 시각화. | **추억의 맥락화:** 관계가 시간의 흐름 속에서 어떻게 발전했는지 스토리텔링이 가능해짐. |
| **관계 중심성** | 사용자의 관계 네트워크 내에서의 위치 파악. | **관계의 중요도 인식:** 사용자는 자신이 누구와 가장 깊은 관계를 맺고 있는지, 관계의 우선순위를 설정하는 데 도움을 받음. |

**결론:** 이 데이터는 사용자가 **'무엇을 모았는가'**에서 **'어떻게 연결되어 있는가'**로 관심사를 전환하도록 유도하며, 이는 플랫폼의 핵심 가치인 **'관계의 감정적 맥락 아카이빙'**을 극대화합니다.
