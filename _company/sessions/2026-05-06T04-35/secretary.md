# 📝 Collect 프로젝트 기획 요약 보고서 (최종 정리본)

### 🎯 1. 프로젝트의 목표: 왜 Collect가 필요한가요?

**핵심 목표:** 기념일의 가치를 '물질적 교환(돈)'에서 **'관계의 감정적 역사 아카이빙'**으로 재정의하는 것입니다.

*   **문제점:** 기존 기념일 문화는 돈에 초점을 맞춰, 관계의 깊이나 감정적 맥락을 기록하지 못해 공허함을 남깁니다.
*   **Collect의 역할:** 돈을 모으는 행위 자체를, **'우리 관계가 얼마나 소중한지 증명하는 과정'**으로 전환하여 새로운 가치를 창출합니다.

### ✨ 2. 핵심 가치 변화: 무엇이 달라지나요?

**가치 변화의 축:** '금액' $\rightarrow$ **'관계의 감정적 깊이와 지속성'**

*   **관계 데이터의 도입:** 사람 사이의 복잡한 관계를 단순한 선이 아닌, **'관계의 지도(Relationship Graph)'**로 분석합니다.
*   **감정적 정량화:** '관계의 깊이'를 F1~F5와 같은 **'감정적 무게 지수'**로 측정하여, 추억에 객관적인 근거와 의미를 부여합니다.
*   **사용자 경험:** 사용자는 단순한 모금에 참여하는 것이 아니라, **자신과 타인의 관계를 '성찰'하고 '증명'하는 경험**을 하게 됩니다.

### 💻 3. 주요 기술적 성과: 무엇을 만들었나요?

**기술적 성과 요약:** 핵심 가치인 '관계의 온기'를 데이터로 처리하고 수익화할 수 있는 기반을 완성했습니다.

*   **관계 그래프 API 구축:** 관계의 연결성, 시간 흐름, 감정적 심리 점수(F1~F5)를 통합하여 **'관계의 온기 점수'**를 계산하는 API 명세와 데이터베이스 로직을 완성했습니다.
*   **수익화 모델 확정:** 단순 기부금이 아닌, 이 **'관계의 통찰력(Insight)'**을 보여주는 보고서나 분석 결과에 대한 **수수료(Transaction Fee)** 구조를 설계했습니다.
*   **디자인/UX 와이어프레임:** 감성적 브랜드 톤을 반영하여, 사용자가 관계의 온기를 시각적으로 체험할 수 있는 랜딩 페이지, 대시보드, 콜렉 페이지의 와이어프레임까지 완성했습니다.
